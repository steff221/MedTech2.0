# MedTech 2.0 — База на податоци (PostgreSQL)

Оваа папка ја содржи целата база како чист PostgreSQL SQL — за да ја отвориш и
разгледаш во **DataGrip** без да зависиш од `localhost` или Docker.

## Датотеки

| Датотека | Што содржи |
|----------|------------|
| `medtech_full.sql` | Сѐ во едно: шема + демо податоци (само отвори и изврши). |
| `01_schema.sql` | Само структурата — enum типови, табели, индекси, тригери. |
| `02_seed.sql` | Само демо податоците (болници, доктори, пациенти, термини...). |

> Сите демо корисници ја делат лозинката: **`magii1002`**

## Важно (зошто нема „датотека што директно се отвора")

PostgreSQL **не е** база во една датотека како SQLite. Податоците живеат во
серверски процес, па DataGrip не може да „отвори папка" и веднаш да прави
пребарувања. Затоа овде базата е зачувана како **SQL скрипта** што ја
реконструира базата на било кој PostgreSQL 16+ сервер.

## Како да ја отвориш во DataGrip

### Вариант 1 — само прегледај го SQL-от
`File → Open` → избери `medtech_full.sql`. Ја гледаш целата шема и податоци како текст.

### Вариант 2 — жива база за пребарување (препорачано)
1. Стартувај локален PostgreSQL (или контејнерот: `cd docker && docker compose up -d postgres`).
2. Во DataGrip додади Data Source → PostgreSQL и поврзи се на серверот.
3. Отвори `medtech_full.sql` во DataGrip, избери ја таа конекција горе десно и
   притисни **Run** (▶). Базата се создава со сите податоци.
4. Сега можеш да пишуваш `SELECT` прашања над реалната PostgreSQL база.

## Освежување на снимката

Датотеките се копии од `backend/src/main/resources/database/`
(`medtech_schema_pg.sql` + `mock_seed.sql`). Ако шемата се промени, повтори го
копирањето за да ја освежиш оваа папка.
